# IADProject – Internet Application Development Labs

##  Overview

This repository contains my **Internet Application Development (IAD) lab work**, built using **ASP.NET Core**. The labs cover key web development concepts such as authentication, role-based access, database connectivity, CRUD operations, and full-stack application development.

**Lab 8** is a **Quiz Management System** and **Lab 9** is a **Survey Management System** — both complete standalone projects. **Lab 6** also includes a **Recommendation System**, originally part of Lab 10/11 (Demand Forecasting).

---

##  Technologies Used

- C#
- .NET Framework / .NET Core
- SQL Server

##  Getting Started

1. **Clone the repository**
   ```bash
   git clone https://github.com/your-username/IADProject.git
   ```

2. **Open** `IADProject.slnx` in Visual Studio.

3. **Set up the database** using the SQL scripts in each lab folder.

4. **Update the connection string** in `appsettings.json` or `Web.config`.

5. **Build and run** with `F5`.
